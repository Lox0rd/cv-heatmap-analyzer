# Тепловая карта

## 1. Назначение

Тепловая карта предназначена для визуализации зон, в которых чаще всего обнаруживаются объекты на видео.

В проекте используются YOLO для обнаружения объектов, ByteTrack для их отслеживания, NumPy для хранения данных и OpenCV для обработки и визуализации тепловой карты.

Тепловая карта позволяет:
- выявлять области с высокой плотностью обнаружений;
- визуализировать распределение людей и транспортных средств в кадре;
- накладывать результат на исходное видео;
- сохранять итоговую карту в виде изображения.

## 2. Структура модуля

Модуль находится в директории `src/heatmap/`.

```text
src/
└── heatmap/
    ├── __init__.py
    ├── generator.py
    └── renderer.py
```

**`generator.py`** отвечает за накопление координат обнаруженных объектов и хранение матрицы тепловой карты.

**`renderer.py`** отвечает за преобразование матрицы в цветное изображение, наложение карты на видеокадр и сохранение результата.

## 3. Принцип работы

Построение тепловой карты состоит из четырёх основных этапов.

### 3.1. Получение обнаружений

На каждом кадре детектор YOLO находит объекты и возвращает список обнаружений. Каждое обнаружение содержит координаты ограничивающей рамки `bbox`:

```python
{
    "label": "person",
    "confidence": 0.92,
    "bbox": (x1, y1, x2, y2),
    "track_id": 3
}
```

Координаты рамки определяют положение объекта в кадре. Идентификатор `track_id` используется трекером для отслеживания объекта между кадрами, но в текущем алгоритме тепловой карты не участвует в расчётах.

### 3.2. Накопление координат

Для каждого обнаружения вычисляется опорная точка — нижняя центральная точка ограничивающей рамки:

\[
x = \frac{x_1+x_2}{2}, \qquad y = y_2
\]

Для людей такая точка приблизительно соответствует положению ног. Это позволяет учитывать место нахождения человека на поверхности, а не центр его тела.

В `generator.py` создаётся двумерная матрица размером с видеокадр:

```python
self.heatmap = np.zeros(
    (height, width),
    dtype=np.float32,
)
```

Изначально все элементы матрицы равны нулю.

При каждом обнаружении вокруг опорной точки выделяется круглая область радиусом `radius`. Значения внутри этой области увеличиваются на единицу.

Таким образом, матрица хранит количество накопленных наблюдений в каждой области изображения.

### 3.3. Сглаживание и нормализация

Накопленная матрица содержит отдельные области повышенных значений. Для получения плавного изображения применяется гауссово размытие:

```python
blurred = cv2.GaussianBlur(
    self.heatmap,
    (0, 0),
    sigmaX=15,
    sigmaY=15,
)
```

Параметры `sigmaX` и `sigmaY` определяют степень сглаживания по горизонтали и вертикали. Чем больше значения, тем более широкими и плавными становятся области.

После размытия значения нормализуются в диапазон от 0 до 255. Максимальному значению соответствует 255, минимальному — 0.

Нормализация позволяет адаптировать интенсивность цветов к накопленным данным.

### 3.4. Цветовая визуализация

Для преобразования нормализованной матрицы в цветное изображение используется функция:

```python
cv2.applyColorMap(
    normalized,
    cv2.COLORMAP_JET,
)
```

Палитра `COLORMAP_JET` использует разные цвета для отображения интенсивности значений.

В результате:
- синие области соответствуют низким значениям;
- зелёные и жёлтые области — промежуточным;
- красные области — наиболее высоким значениям.

Цвет отражает относительную интенсивность накопленных наблюдений в пределах текущей карты, а не абсолютное количество объектов.

## 4. Наложение на исходное видео

Для совмещения тепловой карты с видеокадром используется взвешенное смешивание изображений:

```python
result = cv2.addWeighted(
    frame,
    1 - alpha,
    heatmap_image,
    alpha,
    0,
)
```

Параметр `alpha` определяет прозрачность цветной карты:

- `alpha = 0.3` — исходное видео хорошо различимо;
- `alpha = 0.5` — баланс между видео и тепловой картой;
- `alpha = 0.8` — цветная карта выражена сильнее.

Для корректного наложения исходный кадр и тепловая карта должны иметь одинаковые размеры.

## 5. Использование в основном цикле

Генератор и рендерер создаются до начала обработки видео:

```python
heatmap_generator = HeatmapGenerator(
    width=info["width"],
    height=info["height"],
)

heatmap_renderer = HeatmapRenderer()
```

На каждом кадре после получения обнаружений выполняется накопление данных:

```python
heatmap_generator.update(detections)
```

Для отображения результата карта накладывается на исходный кадр:

```python
display_frame = heatmap_renderer.overlay(
    frame,
    heatmap_generator.get_heatmap(),
    alpha=0.5,
)
```

Полученный кадр можно показать в окне или записать в выходной видеофайл.

После завершения обработки итоговая карта сохраняется:

```python
heatmap_renderer.save(
    heatmap_generator.get_heatmap(),
    "data/output/heatmap.jpg",
)
```

## 6. Основные параметры

| Параметр | Назначение |
|---|---|
| `width`, `height` | Размер матрицы, соответствующий видеокадру |
| `radius` | Радиус области накопления вокруг точки обнаружения |
| `sigmaX`, `sigmaY` | Степень сглаживания тепловой карты |
| `alpha` | Прозрачность при наложении на исходный кадр |
| `COLORMAP_JET` | Цветовая палитра визуализации |

Увеличение радиуса расширяет область накопления для каждого обнаружения. Увеличение параметров размытия делает карту более плавной, но уменьшает детализацию локальных зон.

## 7. Итог

Тепловая карта в проекте представляет собой двумерную матрицу накопленных обнаружений, преобразованную в цветное изображение.

YOLO определяет объекты на видеокадрах, генератор накапливает их координаты, а рендерер выполняет сглаживание, цветовую визуализацию и наложение результата на видео.

Такое разделение позволяет независимо развивать алгоритм накопления данных и способы отображения тепловой карты.
