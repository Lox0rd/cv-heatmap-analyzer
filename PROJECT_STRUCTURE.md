# Корневые файлы

## `README.md`

Основная документация проекта.

Содержит:

* описание проекта;
* цель разработки;
* основные возможности;
* инструкции по установке;
* инструкции по запуску;
* примеры использования;
* информацию о разработчиках.

---

## `TECHNOLOGIES.md`

Описание технологий, используемых в проекте.

В документе объясняется назначение:

* Python;
* YOLO / Ultralytics;
* OpenCV;
* NumPy;
* Matplotlib;
* Pillow;
* PyQt6;
* CometAPI;
* Qwen-VL / GPT-4o;
* Visual Studio Code.

## `PROJECT_STRUCTURE.md`

Текущий документ.

Содержит описание структуры проекта и назначения отдельных каталогов и файлов.

## `.gitignore`

Список файлов и каталогов, которые не должны попадать в Git-репозиторий.

Например:

* виртуальное окружение;
* API-ключи;
* видео;
* изображения;
* веса моделей;
* результаты анализа;
* временные файлы.

# `main.py`

Главная точка входа в приложение.

Запуск проекта выполняется командой:

```bash
python main.py
```

`main.py` должен отвечать только за запуск приложения и связывание основных компонентов.

Основная логика проекта должна находиться внутри каталога `src/`.

---

# Каталог `src/`

`src/` содержит исходный код приложения.

Компоненты разделены по назначению, чтобы не помещать всю логику проекта в один файл.

---

# `src/config/`

Отвечает за конфигурацию приложения.

## `settings.py`

Содержит общие настройки программы:

* параметры YOLO;
* параметры обработки видео;
* настройки тепловой карты;
* настройки API;
* пути к файлам;
* значения по умолчанию.

Например:

```text
Confidence: 0.5
FPS анализа: 10
Прозрачность heatmap: 0.7
```

---

# `src/detection/`

Компоненты компьютерного зрения, связанные с обнаружением и отслеживанием объектов.

## `detector.py`

Отвечает за работу с YOLO.

Основные задачи:

* загрузка модели;
* передача кадра в модель;
* получение обнаруженных объектов;
* получение координат;
* получение confidence;
* фильтрация объектов по классам.

Пример результата:

```text
Person
x1: 120
y1: 80
x2: 180
y2: 250
confidence: 0.91
```

---

## `tracker.py`

Отвечает за отслеживание объектов между кадрами.

Например:

```text
Кадр 1 → Person ID 1
Кадр 2 → Person ID 1
Кадр 3 → Person ID 1
```

Это позволяет анализировать траектории движения объектов.

---

# `src/video/`

Работа с видео и последовательностью кадров.

## `video_processor.py`

Отвечает за:

* открытие видео;
* подключение к камере;
* чтение кадров;
* получение FPS;
* изменение размера кадров;
* пропуск кадров;
* передачу кадров в YOLO.

Основная технология — OpenCV.

---

# `src/heatmap/`

Компоненты построения и визуализации тепловой карты.

## `generator.py`

Отвечает за математическое формирование тепловой карты.

Основная технология — NumPy.

Принцип:

```text
Координаты объектов
        ↓
Массив NumPy
        ↓
Накопление активности
        ↓
Тепловая карта
```

---

## `renderer.py`

Отвечает за визуальное представление тепловой карты.

Используется Matplotlib.

Здесь реализуются:

* цветовые схемы;
* прозрачность;
* размытие;
* сглаживание;
* наложение тепловой карты на исходное изображение;
* сохранение результата.

---

# `src/zones/`

Работа с зонами интереса.

## `zone_manager.py`

Отвечает за создание и управление зонами.

Например:

```text
┌──────────────────────────┐
│                                                    │
│         ┌───────────────┐         │
│         │     Вход                    │         │
│         └───────────────┘         │
│                                                    │
│                ┌─────────┐              │
│                │ Касса           │              │
│                └─────────┘              │
│                                                     │
└──────────────────────────┘
```

Функции:

* создание зоны;
* изменение зоны;
* удаление зоны;
* переименование;
* определение нахождения объекта внутри зоны;
* сохранение зон.

---

# `src/analysis/`

Логика анализа собранных данных.

## `analyzer.py`

Используется для расчёта статистики:

* количества объектов;
* плотности объектов;
* времени нахождения;
* количества входов;
* количества выходов;
* среднего времени нахождения;
* наиболее активных зон.

Например:

```text
Вход:
700 обнаружений

Касса:
500 обнаружений

Стеллаж:
300 обнаружений
```

---

# `src/ai/`

Интеграция с внешними AI-моделями.

## `vision_api.py`

Отвечает за взаимодействие с CometAPI.

Используется для отправки изображений и получения результатов от:

* Qwen-VL;
* GPT-4o;
* других поддерживаемых мультимодальных моделей.

Пример:

```text
Тепловая карта
      ↓
  CometAPI
      ↓
   Qwen-VL
      ↓
Текстовое описание
```

Например:

> Наибольшая концентрация людей наблюдается возле входа.

# Каталог `models/`

Содержит локальные веса моделей компьютерного зрения.

Например:

```text

├── yolov8n.pt
└── yolov8s.pt
```

Файлы моделей не должны храниться в Git, если они имеют большой размер.

Поэтому в каталоге находится:

```text

```

который позволяет сохранить сам каталог в Git.

# Принцип разделения проекта

Каждый модуль отвечает только за свою область:

| Каталог     | Ответственность              |
| ----------- | ------------------------------- |
| `config`    | Настройки                     |
| `detection` | YOLO и tracking                 |
| `video`     | Видео и кадры                |
| `heatmap`   | Построение тепловой карты  |
| `zones`     | Зоны интереса                |
| `analysis`  | Статистика и анализ          |
| `ai`        | Работа с AI API               |
| `export`    | Сохранение результатов      |
| `gui`       | Интерфейс                    |
| `models`    | Веса моделей                 |
| `resources` | Ресурсы интерфейса          |
| `tests`     | Тесты                          |
| `data`      | Входные и выходные данные |
| `docs`      | Дополнительная документация|

Такое разделение позволяет изменять один компонент, не переписывая весь проект. Например, модель YOLO можно заменить на другую, не изменяя интерфейс PyQt6 или алгоритм построения тепловой карты.
