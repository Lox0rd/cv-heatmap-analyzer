# Технологии проекта

## Назначение документа

В данном документе описывается, для чего используется каждая технология в проекте по разработке программного обеспечения для построения тепловых карт зон интереса на основе методов компьютерного зрения.

Основной принцип работы программы:

```text
Видео / камера
      ↓
    OpenCV
      ↓
     YOLO
      ↓
Координаты объектов
      ↓
     NumPy
      ↓
Тепловая карта
      ↓
   Matplotlib
      ↓
     PyQt6
      ↓
Пользователь
```

Дополнительно может использоваться CometAPI для передачи изображений мультимодальным моделям Qwen-VL или GPT-4o.

---

# 1. Python

**Python** — основной язык программирования проекта.

На Python будет реализована практически вся логика приложения:

* загрузка и обработка видео;
* запуск модели YOLO;
* обработка координат обнаруженных объектов;
* расчёт тепловой карты;
* работа с изображениями;
* создание графического интерфейса;
* сохранение результатов;
* взаимодействие с API.

Таким образом, Python является основой проекта и связывает между собой остальные технологии.

# 2. YOLO / Ultralytics

**YOLO (You Only Look Once)** — модель компьютерного зрения для обнаружения объектов на изображениях и видео.

В проекте YOLO используется для определения:

* какие объекты находятся в кадре;
* где эти объекты находятся;
* к какому классу они относятся;
* с какой вероятностью объект был обнаружен.

Например, модель может обнаружить на кадре:

```text
person → x=120, y=80, width=50, height=150
person → x=350, y=100, width=50, height=150
car    → x=250, y=300, width=180, height=100
```

Полученные координаты объектов затем используются для построения тепловой карты.

**Ultralytics** — библиотека и экосистема, через которую удобно использовать модели YOLO в Python.

### Роль в проекте

> YOLO отвечает на вопрос: **«Что находится на изображении и где оно находится?»**

---

# 3. OpenCV

**OpenCV (Open Source Computer Vision Library)** — библиотека для обработки изображений и видео.

В проекте OpenCV может использоваться для:

* открытия видеофайлов;
* подключения к камере;
* получения отдельных кадров;
* изменения размера изображений;
* преобразования цветовых пространств;
* рисования прямоугольников вокруг обнаруженных объектов;
* наложения изображений;
* сохранения кадров;
* базовой обработки изображений.

Например, после обнаружения человека YOLO передаёт координаты его ограничивающей рамки, а OpenCV может визуально нарисовать эту рамку на кадре.

### Роль в проекте

> OpenCV отвечает за **получение и обработку изображений и видеокадров**.

# 4. NumPy

**NumPy** — библиотека для работы с массивами и выполнения математических операций.

Она особенно важна для реализации тепловой карты.

Изображение или тепловую карту можно представить в виде двумерного массива чисел:

```text
[
    [0, 0, 0, 1, 2, 5],
    [0, 0, 1, 3, 7, 9],
    [0, 1, 4, 8, 9, 5],
    ...
]
```

Число в каждой позиции может показывать, сколько раз объект находился в соответствующей области изображения.

Например:

```python
heatmap = np.zeros((1080, 1920))
```

После обработки каждого кадра соответствующие области массива увеличиваются.

В результате получается распределение активности:

```text
низкая активность   → 0
                      → 10
                      → 50
                      → 100
высокая активность → 500
```

### Роль в проекте

> NumPy является математической основой для **накопления и обработки данных тепловой карты**.

# 5. Matplotlib

**Matplotlib** — библиотека для визуализации данных.

После того как NumPy сформировал массив тепловой карты, Matplotlib используется для его визуального отображения.

Например:

```python
plt.imshow(heatmap, cmap="hot")
plt.colorbar()
plt.show()
```

Matplotlib позволяет:

* отображать тепловые карты;
* создавать графики;
* использовать цветовые шкалы;
* добавлять легенды;
* сохранять результаты в изображения.

Условно результат может выглядеть следующим образом:


### Роль в проекте

> Matplotlib отвечает за **визуализацию результатов анализа и построение тепловых карт**.

# 6. Pillow (PIL)

**Pillow** — библиотека для работы с изображениями.

Она может использоваться для:

* открытия изображений;
* изменения размера;
* обрезки;
* конвертации форматов;
* работы с PNG и JPEG;
* добавления текста;
* подготовки изображений для отображения в интерфейсе.

Pillow является вспомогательной технологией и не обязательно должна использоваться во всех частях проекта.

Если необходимый функционал полностью реализуется с помощью OpenCV и PyQt6, Pillow можно не использовать.

### Роль в проекте

> Pillow используется для **дополнительной обработки и преобразования изображений**.

# 8. CometAPI

**CometAPI** — API, через который приложение может взаимодействовать с внешними AI-моделями.

В проекте его можно использовать для передачи изображений мультимодальным моделям, например Qwen-VL или GPT-4o.

Общий принцип:

```text
Изображение
     ↓
 CometAPI
     ↓
AI-модель
     ↓
Текстовый ответ / анализ
```

Например, программа может обнаружить область с большим количеством людей и передать её изображение модели.

Модель может сформировать описание:

> «В данной области наблюдается скопление людей возле входа.»

Это позволяет дополнить обычное обнаружение объектов более сложным анализом.

### Роль в проекте

> CometAPI используется для **интеграции внешних мультимодальных AI-моделей с программой**.

---

# 9. Qwen-VL / GPT-4o

**Qwen-VL и GPT-4o** — мультимодальные AI-модели, способные анализировать изображения и текст.

Они могут использоваться как дополнительный интеллектуальный модуль.

Например, YOLO может сообщить:

```text
Обнаружено:
- 15 человек
- 2 автомобиля
- 1 велосипед
```

А мультимодальная модель может дополнительно интерпретировать изображение:

> «Большинство людей сосредоточено возле входа. Вероятно, эта область является зоной повышенного интереса.»

Таким образом, задачи можно условно разделить:

### YOLO

> **«Что и где находится?»**

### Qwen-VL / GPT-4o

> **«Что происходит и как это можно интерпретировать?»**

Мультимодальная модель не является обязательной частью построения самой тепловой карты. Она может использоваться как дополнительный модуль для анализа и формирования текстовых выводов.
